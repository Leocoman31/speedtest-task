# Замер скорости скачивания

Консольный скрипт на Node.js. Делает 10 последовательных запросов к указанному адресу, дожидаясь полного скачивания ответа на каждый, и выводит среднее время запроса, общий объём данных и скорость скачивания.

## Требования

- Node.js 18 или новее (используется встроенный `fetch`)
- Внешние зависимости не нужны

## Запуск

```bash
node speedtest.js <url>
```

Пример:

```bash
node speedtest.js https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Лучше брать «тяжёлый» файл (несколько МБ): на маленьких файлах результат сильно зависит от задержки соединения, а не от пропускной способности.

## Что выводится

По каждому запросу: время, размер и скорость. В конце итог:

```

# 4: 89.080 с, 14.68 МБ, 1.32 Мбит/с
# 5: 12.464 с, 14.68 МБ, 9.42 Мбит/с
# 6: 29.676 с, 14.68 МБ, 3.96 Мбит/с
```

## Единицы измерения

- Основная единица скорости: **Мбит/с** (мегабиты в секунду), как у интернет-провайдеров. Дополнительно показано в МБ/с.
- 1 МБ = 1 000 000 байт, 1 Мбит = 1 000 000 бит, 1 байт = 8 бит.
- Время указано в секундах.

## Как считается

- **Среднее время запроса** = сумма времени всех успешных запросов / их количество.
- **Общий объём** = сумма байт тела ответов (заголовки не учитываются).
- **Скорость** = общий объём в мегабитах / суммарное время запросов. Паузы между запросами не учитываются, так как запросы идут подряд.

## Детали реализации

- Запросы строго последовательные: следующий начинается после полного скачивания тела предыдущего.
- Кэширование отключено (`Cache-Control: no-cache`), сжатие отключено (`Accept-Encoding: identity`), чтобы считать реально переданные данные.
- Если запрос завершился ошибкой (сеть, HTTP-статус не 2xx), это выводится в консоль, запрос не учитывается в статистике, остальные продолжают выполняться.
- Если все запросы упали, скрипт завершается с кодом 1.
